# Discord

Server: Dapr, invite link [diagrid.ws/dapr-discord](https://diagrid.ws/dapr-discord)
(the `Discord` entry in `config.toml`).

## Discovery splash

`images/discord-discovery-splash.png` (1920x1080, the 16:9 size Discord
recommends). It is the image on the server's card in Server Discovery, set
under Server Settings > Discovery. The server icon sits over the lower left of
the card, so that corner is empty.

Unlike the other banners this is a card rather than a strip, so the headline
wraps to three lines, the same as the Open Graph card.
